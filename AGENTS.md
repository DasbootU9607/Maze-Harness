# Repository instructions

These instructions apply to Maze-Harness.

- Commit and push routine skill and documentation updates directly to `main`. This replaces any inherited branch-first or mandatory pull-request workflow for this repository.
- Create a separate branch or pull request only when the user requests one.
- Synchronize with `origin/main` before committing. Preserve existing work and do not force-push or rewrite published history.
- Keep public content in English. Exclude credentials, private personal information, and machine-specific paths.
- Run checks appropriate to the change before pushing. A repository update does not authorize a package release or deployment.
