# Bridge Convoy reference difficulty

The catalog ranks references only within this mechanism and its complete stated goal. This is the only reference. There is no measured neighboring-case ordering, no player study and no official MazeBench rating. The automatic timeout and 177 input count are not grading criteria. Unused floors and blocked inputs do not count as extra logical stages.
