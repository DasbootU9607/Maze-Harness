# Constrained Transport reference selection

Use [the catalog](reference-catalog.json) with the full case documents. Levels describe relative structural complexity within this skill and the stated objective. They are not an official MazeBench difficulty ranking or measurements of player performance. All current placements are provisional `structural-estimate` judgments; no route count is used as a score.

| Tier | Criterion |
| --- | --- |
| l1 Foundation | A useful contact and accessible transport/recovery with few dependent preparations |
| l2 Combination | Connected preparations, changing input access, or repeated use of a shared tool |
| l3 Planning | Shared-space competition, changing roles or pushing faces, and recovery needed for subsequent work |

| Reference | Tier | Branch and reason | Limits |
| --- | --- | --- | --- |
| [GxF](official-case.md) | l3 | Short-bar offset delivery after helper reconfiguration, reversals and changing player sides; revised endpoint includes return | Legacy necessity results concern the gem goal; the stronger full-return witness is separate |
| [GxG](official-gxg-case.md) | l3 | Short-bar axial reach after interacting exchanges, followed by target repositioning and tool withdrawal | Target freeze and transfer exclusion capped at 6,000 push components; uniqueness is unknown |
| [GxH](official-gxh-case.md) | l3 | Bar changes from initial pusher to parked obstruction; an L is restored and transported using the other L | Scope includes whole-target support loss; exact restoration sequence is a witness choice |

The shared planning tier does not imply an ordering among these branches. GxG demands post-contact repositioning, whereas GxH changes the final tool role and target support behavior. Those dimensions differ together, so a single strict ranking would overstate the evidence. Empty lower tiers are deliberate; do not fabricate an easy fixture to fill them.

Choose GxF for offset use reached through helper competition, GxG for axial reach and post-contact work, and GxH for role reassignment and restoration. Preserve their separate physics and endpoint evidence. Reference selection guides functional design; it does not license copying coordinates or lower the existing default complex-authoring requirements.
