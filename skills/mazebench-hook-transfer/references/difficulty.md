# Relative reference difficulty

These levels organize this skill's references, not official MazeBench difficulty or measured player ability. Read each complete objective and entry before comparing. GxE reaches a passage, FxE collects a gem, and FxG continues through two room-local doorways; those differences confound direct comparisons. Input counts and search expansions are not the grading basis.

| Level | Reference | Basis and rationale |
| --- | --- | --- |
| l1 Contact and continuation | [GxE](official-case.md) | Provisional structural inventory: independently prepare one tool-target pair, create rear contact, then continue passage work. Foundation means a comparison reference, not an easy-room claim. |
| l2 Released-tool reuse | [FxE](official-fxe-case.md) | Provisional structural inventory: release a constrained tool, operate separated targets with different members, recover contact and regain input access. This adds changing roles and repeated use to the single-pair reference. |
| l3 Shared-space coordination | [FxG](official-fxg-case.md) | Human-assigned relative higher placement, mapped to this local level. The witnessed rationale is competing footprints, repeated stance recovery, several changing contact pairs and tool handoff between two passage goals. This is not a playtest result. |

For reference selection, choose GxE for the clearest single-pair contact/release chain, FxE for a released tool and span reuse, and FxG for shared-space recovery and continued work across distinct passages. Extract those functions before choosing new geometry. A lower-level reference does not disable the default complex-authoring contract; a higher-level reference does not make a copied silhouette difficult.

When adding references, preserve stable IDs and source-qualified file families in [the catalog](reference-catalog.json). Record the new case's own human focus and complete replay. Compare preparation, full-body constraints, next-input access, role reuse and recovery. Mark insufficiently comparable references unranked with a reason. Revise a tier only with an explicit basis and rationale; grade changes do not retrospectively strengthen mechanical necessity evidence.
