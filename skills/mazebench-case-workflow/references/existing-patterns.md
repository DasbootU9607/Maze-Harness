# Existing patterns

This workflow is derived from the four Maze Harness mechanism skills. These are patterns for analysis and packaging, not answers to a new case's human-input question. Locate the skill in the current repository or installed skill directories when needed; this workflow does not depend on their absolute paths or on another skill being installed.

| Existing skill | Official cases | Distinct extraction lesson |
| --- | --- | --- |
| `mazebench-boundary-stagger` | HxH | Retain the full approach preparation, boundary-constrained contact cluster and independent offset before the later route-opening move |
| `mazebench-hook-transfer` | GxE; FxE | Identify real input/working/target members, independently reachable docking and further work; additional cases can add target-to-tool role changes and reusable spans |
| `mazebench-constrained-transport` | GxF | Analyze full-footprint delivery, changing helper configurations, usable pushing faces and purposeful recovery in shared space |
| `mazebench-skating-cross` | JxG | Preserve directed stopping, all-arm collision limits, reusable pushing/braking surfaces and the full gem-and-doorway objective |

Inspect `SKILL.md`, `references/mechanism-logic.md`, the complete affected `official-*-case.md` or `official-case.md`, its design/states/checks, and the compatible runtime/verifier. Read code when adapting an observer; do not select it by filename or copy its profile string without checking support.

The common package structure separates source evidence, transferable mechanism logic, design guidance, empty new-map contracts and runnable regressions. Stable relation IDs tie mechanism prose to concrete new geometry. Version receipts detect changed reading material; they do not prove reading, understanding or causal necessity.

Retain distinctions already exposed by these cases: whole rooms versus simplified reconstructions; an observed move versus an indispensable move; a useful contact versus permanent attachment; one replay order versus all successful histories; an exhausted restriction versus a capped search. Exact route lengths, role counts, letter shapes and selected direction sequences are evidence about particular maps, not default quotas for future maps.

When importing an existing case for a new purpose, first collect the human's intended focus. Reuse source bytes and historical evidence only with matching provenance and an accurate statement of scope. Do not present this pattern table as newly performed official-case verification.
